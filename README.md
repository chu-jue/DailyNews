# 📰 DailyNews 每日新闻简报

每天更新科技、AI、美股新闻。

🌐 **访问网站**: https://chu-jue.github.io/DailyNews/

## 主题
- 🤖 科技前沿
- 🧠 AI 人工智能  
- 📈 美股市场

## 自动更新
每天 11:00 (北京时间) 自动抓取最新新闻并更新。

## 本地开发
```bash
# 安装依赖
npm install

# 本地预览
hexo server

# 生成静态文件
hexo generate

# 部署到 GitHub Pages
hexo deploy
```
